# 07 — Validation and reconciliation
Read: `validation/mdep-13-validation-matrix.yml`, `validation/reconciliation/`, `scripts/validate-mdep-13-e2e.ps1`, `tests/test_mdep13_validation_framework.py`.

## VR-01 — INCIDENT
**Difficulty:** Senior. **Scenario:** native command exits 7 but PowerShell itself did not throw. **Deliverable:** classify stage, name runner safeguard, and explain false-PASS risk. **Competency:** evidence-first automation.
## VR-02 — TRACE
**Difficulty:** Intermediate. **Scenario:** Bronze count 1,000; Silver current state 900; Gold daily mart 30 rows. **Deliverable:** explain why count equality is wrong and select two R01–R10 checks. **Competency:** semantic reconciliation.
## VR-03 — STATUS REVIEW
**Difficulty:** Foundation. **Scenario:** matrix says historical `BLOCKED`; final V1 says runtime deferred. **Deliverable:** distinguish `BLOCKED`, `NOT_RUN`, and V1 scope wording. **Competency:** truthful status communication.
