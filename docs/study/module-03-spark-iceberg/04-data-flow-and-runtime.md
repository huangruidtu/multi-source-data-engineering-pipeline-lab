# Module 03 — Data flow and runtime

An incoming location `loc-100`, `updated_at=2026-08-20`, extraction `01:00`, ingestion `01:05`, hash `bbbb` normalizes country `dk` to `DK` and region `nordics`. It is deduplicated inside the batch by key/version. Against existing Silver, a `2026-07-01` replay with hash `zzzz` loses because business time is older. Same business time uses extraction, then ingestion; only an exact timestamp tie compares hash. Equal tuple/hash is a no-op. Valid rows target Iceberg current state; failed shape/reference rows target quarantine. Driver/executor execution, snapshots, S3 files and MERGE are **RUNTIME DEFERRED — not runtime validated**.
